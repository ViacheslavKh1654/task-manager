Task Manager

A task management web application built with React and TypeScript.

Status: In Progress

Tech Stack
React 19 + TypeScript
Vite
Redux Toolkit / React Redux — state management
React Router - routing
React Hook Form - form management
CSS Modules - styling
ESLint
Project Structure
src/
├── app/            # application configuration, router and store
├── components/     # reusable UI components
├── features/       # application features
├── pages/          # application pages
└── shared/         # shared types and reusable elements
Getting Started
npm install
npm run dev
Available Scripts
npm run dev — start the development server
npm run build — build the application
npm run lint — run ESLint
